| #2613 | TURNSTILE.1 — bot check on public forms | 2026-11-27. The public sign-up forms (leads, trial and open week bookings, /corp, consult bookings, event registration and waitlist, host lists, the Givers enquiry) can now run Cloudflare Turnstile, an invisible bot check. It stays off until the Cloudflare widget keys are set. It then runs in monitor mode (logging only) before it is switched to enforce. A Cloudflare outage never blocks a real sign-up. |
