A class reminder says "tomorrow"; with no date on it, yesterday's reminder read as today's and Mia offered a member a class that had already happened. `formatHistoryForClaude` (`src/lib/agent/core.js`) now takes the studio zone: when a conversation reaches back before today, every message is stamped, `[sent Sun 22 Nov]` for an earlier day (with the year when it is not this one) and `[sent today]` for today's, so reminders merged into one turn are told apart line by line. The customer reply, the follow-ups and the approval suggestion pass the zone. A customer cannot forge the stamp and one copied to the start of a reply line is cut. `HISTORY_DATES_RULE` in every prompt variant explains it and tells Mia to read a member's bookings with her tools before naming or changing them. No migration. Not yet tried with a real message. |
