| #2274 | SONOSPLAYERVOL.1 — a Sonos window can set each speaker's own volume | 2026-11-01. A window carried one group `volume`, and a Sonos group set moves each player proportionally from where it already sat, so two speakers left at 10 and 60 by hand stayed lopsided every morning. Each window may now carry `player_volumes: { [playerId]: 0-100 }` on top of its group volume, which stays the default for any speaker not named. `planAction` carries them normalised (`playerVolumes`); `applyOpen` runs group volume → each of the schedule's speakers in that group with a named level → favourite, and a failed player call skips the favourite and stamps nothing, like a failed group call (`sonosSetPlayerVolume`, `POST /players/{id}/playerVolume`). The schedules route and `openapi.js` take the optional record (max 32); the editor shows a slider per selected speaker once a schedule has two or more, defaulting to the window volume with Reset, and sends only the selected speakers' levels. Mig 800 (comment only, applied 2026-11-01) records the key on `sonos_schedules.windows`. |
