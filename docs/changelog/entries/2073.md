Mig 729 adds `org_settings.customer_agent` (nullable) and a BEFORE INSERT/UPDATE fence trigger, so only `service_role`/`postgres` writes it: owners hold table-level client writes on `org_settings`. `resolveAgentSettings` (`src/lib/agent/settings-resolve.js`) merges `DEFAULTS ← org ← studio`, object keys per field; null means inherit. The new org defaults editor (`/api/settings/customer-agent/org`, masters and org admins via `resolveAdminOrgId`, else 404) shows per field which studios inherit, warns before a new value reaches a studio, and offers "Start from a studio's settings". Studios can set `quiet_hours.off`. The membership source comes off the turn's location row, so a failed read cannot make a Glofox studio no-booking. Follow-ups and check-ins at a number-less studio go through the thread's stamped number; a studio with its own number sends unchanged.
