The bare per-location Integrations tab redirects to the hub, and the hub drew a un1t.online card only once a connection existed, so a studio had no visible way to its un1t.online tab before the first connect (Hatch Street needed a deep link). `assembleIntegrationsHub` now marks each `un1t_online` row `offerConnect` when the studio has no registry row and an explicit `membership_source` of `'none'` or `'un1t_online'` (a Glofox studio, or a caller that did not select the column, is never offered it); the card renders those as "Not connected" with a Connect link to `?tab=un1t-online`, with no attention nag. `membership_source` joins the hub's three location selects (page, `GET /api/integrations/hub`, tenants console). |
