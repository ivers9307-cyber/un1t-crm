| #1970 | W0.10 — Strava webhook moved behind a URL token | 2026-10-09. Strava never signs its webhook POSTs, so the old /api/webhooks/strava route took any caller and a known athlete id could trigger fetch/ingest/delete of that athlete's activities. The route is now /api/webhooks/strava/[token] (STRAVA_WEBHOOK_URL_TOKEN, constant-time compare, 404 on POST / 403 on GET with a wrong token, closed when unset) with a per-IP rate limit on POST; the push subscription must be recreated with the tokenised callback URL. |
