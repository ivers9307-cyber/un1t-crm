| #2336 | HOSTPORTAL.4 — share links, event QR, email shortcut, page preview, new ratings | 2026-11-09. The second release of the host portal reorganisation (spec `docs/superpowers/specs/2026-11-09-host-portal-release-2-design.md`): the five extras held back from #2332 / #2333. **Promote tab:** "Copy a link for" Instagram, WhatsApp, Facebook, TikTok, X and LinkedIn (`src/lib/event-share-links.js`, `EventShareLinks`), each link carrying `utm_source=<token>` so the Insights tab can tell the sources apart; a QR code (`GET /api/host/events/[id]/qr`, PNG, tagged `utm_source=qr`, with `qr: 'QR code'` added to the attribution labels); and "Write an email about this event" (`POST /api/host/events/[id]/announce-draft`), which inserts a DRAFT `host_campaigns` row for the host's contacts and opens it in the composer via `?open=<id>`. The draft is three short HTML lines (name; date · times · venue; a "Book your place" link the send pipeline tags with `hc`), is only made for an event that is on sale and has not taken place (`announceBlockedReason` gives the route's 409 sentence and the button's sentence: not published, waiting for approval, off sale, already taken place), and a second click reuses an identical untouched draft. Nothing is sent by this feature. `HostEmails` cleans `?open` / `?notice` from the address once handled. `src/lib/host-event-url.js` (`hostEventPublicUrl`) is now the one builder of the public event URL for the Promote page, the QR and the draft, and is registered in `customer-link-paths.test.js`. **Your page:** a same-origin iframe preview of the saved public page beside the editor from `lg` up, reloading after each save, behind a Show preview toggle on a phone. **Overview:** under "Needs your attention", up to three neutral lines for events that received ratings in the last 7 days (`loadRecentRatingCounts` in `src/lib/host-rollup.js`), linking to the event's Insights tab; no "seen" marker, so no write. **Guard:** `tests/host-event-columns-guard.test.js` checks every `loadHostEvent(…, columns)` list (and its embeds) against the schema replayed from the migrations, which `check:select-columns` cannot read: a phantom column there would 404 a tab for every host with green tests. Both new routes gate on the host session, answer 404 for another host's event and are registered in `openapi.js`. Read-only apart from creating an email draft; no migration. Known: the email draft opens in the composer's Plain text box, which shows its markup (a notice explains the angle-bracket codes and points to Preview as sent). Not checked in a browser. |
