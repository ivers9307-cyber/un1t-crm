| #2499 | RAFFLE.4 — raffle prices as the cheapest mix of deals | 2026-11-20. Any number of raffle tickets (till and online) is now charged at the cheapest combination of the raffle's ticket options and single tickets, e.g. 20 tickets with "10 for €20" is €40, with a label naming the deals used ("2 × 10 for €20", "5 for €12 + 2 singles"). The same search runs in priceForQuantity and in the database (new raffle_mix_price, sell_raffle_tickets same signature), so the screen and the charge agree. Mig 867 applied before deploy. |
