| #2275 | MCP.1 — staff MCP server: Claude connects to the CRM as the signed-in person | 2026-11-01. A Model Context Protocol endpoint at `/api/mcp` (canonical host only, `mcp-handler` 2.x, stateless Streamable HTTP). Supabase Auth's OAuth 2.1 server issues the token; `/oauth/consent` (public on every host, all four allowlists) is the approval screen and shows the client's redirect host beside its name; `/.well-known/oauth-protected-resource` serves the RFC 9728 metadata. The door (`src/lib/mcp/auth.js`) refuses only a bad, expired or unbound token: it verifies the token with the anon client and binds it to the `getCurrentUser()` session (impersonation refused); the proxy refuses an OAuth-issued token on every other `/api` path. Policy refusals are tool-level codes (`mcp_disabled`, `assistant_permission`, `forbidden`, `not_found`, `invalid_input`, `rate_limited` at 120/min, `conflict`, `tool_failed`). Connecting needs the existing `assistant` web permission; every tool takes an optional `studio_id`, resolves a studio the person holds it at, and is fenced by that studio or by the readable contact set (resolved studio's organisation, switch on, `assistant` + `contacts`). 18 tools in `src/lib/agent-tools/` (`tests/agent-tools-guard.test.js` is the floor): whoami, roster/time-off/allowance/staff/templates, hours and cost reports (cost for `RATE_REPORT_VIEWER_ROLES`), contact search/detail, pipeline, tasks, classes/roster/appointments, and the assistant's three writes (create shift, contact, activity). Org switch `org_settings.mcp_enabled` (mig 801, default off) on the Integrations hub's Agent access card; Connected apps card on `/account` (`listGrants`/`revokeGrant`); `mcp_tool_calls` log (tool, outcome, duration: never arguments) purged after 90 days by `purge-mcp-tool-calls` (heartbeat row mig 802, applied after deploy). Rollout needs the Supabase Site URL on `crm.repset.ie`, the redirect allow-list admitting `/auth/callback**`, the OAuth server with Authorization Path `/oauth/consent` and dynamic client registration on; `docs/architecture/INTEGRATIONS.md` § Staff MCP server. |
