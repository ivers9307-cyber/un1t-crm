| #2535 | INVOICEPREP.1 — invoice emails are never lost on a retry | 2026-11-22. The invoices inbound webhook claimed its dedup key before storing anything, so a storage or insert failure made Postmark's retry answer "deduped" and the invoice was gone. Every failure now releases the claim, a repeat delivery is processed again, and `ingestInboundEmail` stores each attachment once, so a retry finishes the job without a duplicate. Mail that matches no studio is recorded in `invoice_inbound_strays` (masters see it on /invoices) instead of only logged. Inline signature logos are skipped (under 100 KB, and only beside a real attachment), a file is judged by its bytes, the email text is kept and shown on an open row, and every stored file gets a SHA-256 hash. Migration 868 (applied). Not covered: emails over about 3.3 MB of attachments still never reach the webhook. |
