| #2529 | COOLDOWN.1 — a sequence's re-enrolment cooldown now lets people go through it again | 2026-11-22. Setting a cooldown of N days on a sequence now does what its hint always promised: once N days have passed since a person's last run ended (completed or exited), the next time they match they go through the sequence again. Until now nobody could ever re-enter, because the enrolment table holds one row per person per sequence. That row is now started again for the new run, and the run that ended is kept in its history, so a person can still never be in the same sequence twice at once. The "everyone who matches" sweep offers these people again after the cooldown, newcomers first. A trigger tied to one event (a purchase, a booking, an order, an account) never runs twice for that same event, and the automations-exempt flag now also covers re-entries. Leave the cooldown empty or 0 and each person still goes through once. The editor hint says this again. Sending, audience and consent rules are unchanged. No migration. |
