| #2574 | INBOXFOLLOW.1 — the inbox has five queues, and a coach's thread stays theirs | 2026-11-25. The inbox now sorts conversations into Needs reply, Mia needs help, Waiting, Approvals and All, with a count on each. Needs reply lists whoever has waited longest first, and each row shows how long ("waiting 2h 10m", or "quiet 2 days" when we are waiting on the customer), how long the WhatsApp window has left ("closes in 3h", "template only" once it has closed) and, when it matters, why the thread is where it is (snoozed, Mia nudged, no reply after nudge, gone quiet). Rows move between queues each minute without a reload. Once a coach replies in a conversation it stays theirs until a coach completes it: it is not resolved automatically, and Mia sends the customer nothing on it (no answer, holding message or handoff notice), on WhatsApp and Instagram. A coach's thread that goes quiet for the studio's window returns to Needs reply. The badge, the home queue and the phone count with the same rules. The inbox list now carries every conversation that needs someone, not only the latest 50. |
