| #2570 | SALEALERT.2 — the sale push plays a bundled cha-ching | 2026-11-23. The server names `cha_ching.wav` on the `sale` push and the `expo-notifications` plugin bundles the file at build time, so a binary cut after this plays a cash-register sound; older binaries play the default chime. `runtimeVersion` and `version` do not move, and Android keeps the `reminders` channel sound. The file name is `[a-z0-9_]` only because the plugin copies it into Android `res/raw`. |
