The old test handed the overlay a plain element, which a server never does. Now the `[slug]` route's preview passes the card's props as plain data (`offerLayout.offerProps`, plus `offerLive` for a promo's key, platform and tokens; nothing the card element did not already carry, and not sent on the public page) and `liveOffer` builds the card from them with the live block's words. The words' own box now carries a scrim at every width (black at 85%, fading out over its 4rem top padding) and the whole-box gradient is gone; sizes and heights are unchanged (at 375px the box is 256px and the card starts at 344px, as before). Shared by every one-class page (/trial, /corp).
