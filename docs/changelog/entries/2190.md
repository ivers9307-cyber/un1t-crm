| #2190 | CHARITY.14 — upload a charity-day video file, or link one: both options | 2026-10-24. The Charity day section gains an upload control beside the YouTube/Instagram link: the file goes straight from the browser to the public branding bucket through a signed URL from the new `POST /api/events/[id]/video/signed-upload` (races at the event's studio, 404 off-studio, MP4/WebM/MOV, the bucket's 200MB ceiling), saved as `charity.video_file_url`, which the settings schema accepts only under `race-video/<event id>/`. The public page plays the file tap-to-play with the hero image as its poster; the file wins over the link when both are set. No migration. |
