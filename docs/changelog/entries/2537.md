A studio's image library refused GIF files, so an animated image could not go into an email (the email tools place only library images). `/api/landing-page-settings/media` and the landing page image pickers now accept `image/gif`, the library lists `.gif` files as images, and the browser uploader passes a GIF through without compressing it (a canvas keeps only the first frame). **Mig 869** adds `image/gif` to the public `branding` bucket's allowed types: apply it before the deploy.
