| #2615 | MCPBEARER.1 — getCurrentUser() refuses an OAuth-issued token | 2026-11-27. A Bearer token minted for an MCP connector (it carries `client_id`) now resolves to nobody in `getCurrentUser()`, not just in the proxy, so a public route can never be reached with one. Only the MCP door (`getCurrentUserForMcp`, called by `verifyMcpToken`) accepts it; a guard test fails any other caller. No migration. |
