| #2606 | CONDBLOCKS.1 — show parts of an email only to some people | 2026-11-26. An email body or subject can now hold a block that only some recipients see: {{#if member}}…{{else}}…{{/if}} for current members, {{#if first_name}}…{{/if}} for people with a first name on file, and {{#if stage=dormant}}…{{/if}} for a pipeline stage. {{#unless …}} does the opposite. It works in campaigns, automation emails and both test sends. A condition the CRM does not know is left visible as written, so a typo shows up in the test send instead of silently hiding text. |
