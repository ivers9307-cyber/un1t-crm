| #2013 | ADOPTDOMAIN.1 — email domain: adopt a domain the platform's Postmark account already holds (master only, unclaimed) | 2026-10-11. Live: provisioning UN1T Group's sending domain created its Postmark server (21100951) and webhooks, then POST /domains failed "Domain already exists." because Postmark domains are account-level and the platform's account already held the name; the row stayed `pending`. `provisionEmailDomain` now catches that refusal (`isDomainAlreadyExistsError`), finds the domain with paged `GET /domains` (`findTenantDomainByName`) and adopts it ONLY when the caller is a platform master (`user.isMaster`/`profileRole`, defaults false) AND no other org's `tenant_email_domains` row holds that `sending_domain` or `postmark_domain_id` (a failed check fails closed); anyone else gets an operator-neutral 409 ("use a subdomain such as mail.<domain>, or contact support"). An adopted domain gets the same row write as a created one (live only when DKIM + Return-Path both verify, else verifying; last_error cleared). A retry reuses the existing server; other Postmark errors are unchanged; the from local part is stored lower-case. |
