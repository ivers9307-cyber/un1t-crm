| #2595 | MERGEFALLBACK.1 — merge tags can have a fallback | 2026-11-26. A merge tag in an email can now carry a fallback after a bar: "Hi {{first_name|there}}," reads "Hi Anne," for Anne and "Hi there," for a contact with no first name, where before it went out as "Hi ,". It works for every merge tag the CRM fills, in campaigns and automation emails; tags without a bar work as before. |
