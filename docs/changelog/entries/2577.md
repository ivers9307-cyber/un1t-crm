| #2577 | INBOXFOLLOW.4 — the staff app shows the same queues as the web, and staff can snooze from the phone | 2026-11-25. The Messages tab in the staff app now has the web inbox's five queues (Needs reply, Mia needs help, Waiting, Approvals, All) with a count on each, and opens on Needs reply, longest-waiting first. Each row shows how long the customer has waited ("waiting 2h 10m", or "quiet 2 days" when we are waiting on them), how long the WhatsApp window has left ("closes in 3h", "template only" once it has closed) and, when it matters, why the thread is where it is (snoozed until a time, Mia nudged, no reply after nudge, gone quiet, snooze ended). The words are the same code the web uses, and times are the studio's. The list now includes every conversation that needs someone, not only the newest 100, so an old waiting thread or a snooze reminder that has gone off is never missing. Inside a thread staff can snooze it for later today, tomorrow, 3 days or next week with an optional note, unsnooze it, or dismiss a reminder that has gone off; a customer message that arrived in the meantime is shown instead of being buried. Each thread says who has it: "Handled by Mia", "Handled by" a coach's first name, "Mia paused" or "Waiting for a person". On the web a snooze reminder that has gone off can also be dismissed from the thread. This reaches phones as an over-the-air update when it merges. |
