| #1931 | WA-APPECHO.1/.2 — phone-app coexistence echoes count as staff and move the thread up the inbox (C106 d) | 2026-10-03. Latent, not live: prod has 0 echoes because Stillorgan is Cloud API only. A reply typed in a studio's linked WhatsApp Business phone app (`smb_message_echoes`) was stored as an automation: column default `source='api'`, no `sent_by`. So it did not take the thread over from Mia, did not block a first-class check-in (C104), and did not count as a human reply for the handoff SLA or auto-resolve. Changes: the ingest stores echoes as `source='app_echo'` (allowed by the CHECK since mig 259, so no migration) and applies `manualTakeoverPatch`, as the inbox send does. A failed takeover write is logged and reported, never thrown. History rows are unchanged. The new `src/lib/whatsapp-staff-sources.js` is the one staff rule (`sent_by` set, or source operator/app_echo; never agent). Mia's takeover and re-arm check (`isHumanOutbound`), the SLA reply read (`.or()` filter) and the check-in runner (`isStaffOutbound`) use it. The tier budget excludes phone-app rows. Inbox, analytics and the follow-up ladder already counted every outbound row not sent by Mia as staff, so they are unchanged. WA-APPECHO.2 (review): an echo now also bumps the thread's `last_message_at` / `last_message_direction` / `last_message_preview`, as the inbox send, Mia and the inbound webhook do. Before it, a thread answered from the phone stayed in Needs reply (that queue is `last_message_direction = 'inbound'`, web and mobile) and never moved up. The bump uses the echo's own time and only applies when it is newer than the thread's `last_message_at`, so a late or out-of-order echo never hides a customer's newer message (same guard as the mail sent-lane bump). It is a separate write from the take-over; either failing is logged without the body and reported, never thrown. `history_sync` is no longer a staff source: nothing writes it, and if anything did, `created_at` would be the import time, and every staff reader orders or windows on `created_at`, so an old phone message would read as a fresh staff reply (Mia aborts a turn, the SLA sweep auto-resolves the handoff, the check-in is blocked). It still counts as a phone-app source for the tier budget. Web only, no OTA. |
