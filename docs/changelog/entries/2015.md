| #2015 | FROMDOMAIN — campaigns and sequences may send from any address on the org's verified domain | 2026-10-11. Richard's decision: a campaign or sequence `from_email` is SENT when its domain equals the org's LIVE verified sending domain (exact, case-insensitive; a subdomain never matches; never on the platform/global sender), else the resolver's own address goes out (W1.E2 unchanged). New `src/lib/from-address.js` (`pickFromAddress`, `withRequestedFrom`); `resolveEmailSender`'s live sender exposes `sendingDomain`. Applied in campaign-sender, `sendMarketingEmail` (sequences, new `fromEmail`), and the campaign send-test; `email_sends.from_email` logs the address used. Accept-and-ignore: any valid `from_email` is still stored as given; the four campaign write routes return `from_address { requested, sends_as, on_verified_domain, verified_domain }` when the body carried one. The From NAME is unchanged. W1.S2's editor must restore a From-address input. |
