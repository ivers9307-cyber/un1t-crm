# check-secrets allowlist — suppressions for scripts/check-secrets.mjs.

# Format: one finding per line —
#   path/to/file            (file-level findings, e.g. the key-material-file rule)
#   path/to/file:LINE       (content findings; LINE is the reported 1-based line)
# Lines starting with '#' and blank lines are ignored.
#
# EVERY entry must carry a justification comment above it. An entry means a
# human confirmed the finding is intentional and NOT secret material. Never
# allowlist an actual credential — remove it and rotate it instead. Stale
# entries (matching nothing) print a CI warning; delete them.
